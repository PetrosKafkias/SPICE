GENERAL DESIGN DIRECTION
Create a refined desktop web interface for the SPICE Co-Creation Hub. The design should be professional, calm, friendly, and trustworthy. It should support non-technical users while still looking robust enough for municipality staff, planners, facilitators, and administrators.

Do not copy the example exactly. Use it only as inspiration for:
- a persistent left sidebar,
- a top bar,
- content cards,
- clear sections,
- tool-based navigation,
- data/insight panels,
- selected states,
- role/user controls.

SPICE VISUAL LANGUAGE
Use a palette inspired by the SPICE logo:
- Primary dark green for navigation, active states, headings, and key buttons.
- Bright/fresh green for positive actions, progress, selected filters, and participation indicators.
- Soft mint / pale green for backgrounds, highlighted cards, and subtle surfaces.
- Warm off-white / beige for the main page background.
- Dark charcoal or deep forest green for body text.
- Limited secondary accents such as soft blue or muted yellow only for information, warnings, or phase labels.

Avoid harsh black, overly saturated colours, and heavy gradients. Use soft shadows, rounded cards, generous padding, and clear visual hierarchy.

LAYOUT
Create a desktop layout with:
- A fixed left sidebar.
- A clean top header.
- A main content area organised into cards and panels.
- Clear page title area.
- Tool cards and insight panels.
- Strong active navigation state.
- Consistent spacing and alignment.

The layout should feel lighter and more elegant than the reference screenshot. Use more breathing space, better typography, clearer grouping, and more refined card styling.

INTERACTIONS / STATES
